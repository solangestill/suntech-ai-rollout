# 上海玄甲安全公司AI应用推进方案

以部门需求为主的交互式展示网页。电商部主用 Accio Work，其他部门主用 WorkBuddy，电商通用工作按需使用 WorkBuddy 辅助。

## 内容

- 八个部门的首批任务与扩展方向，包含财务报表数据分析
- 组织分工、培训、公共资料与 Skill 维护
- 验收、阶段推进、每周复盘及台账
- 末尾飞书备用介绍与对比

## 使用

浏览器直接打开 `index.html`。左右方向键翻页，N 显示讲解提示，F 全屏。也可切换连续阅读或打印。

页面无外部脚本、字体和图片依赖，无统计跟踪或服务器端数据收集。展示中的勾选不保存，刷新重置。

## 部署

使用 GitHub Pages，从 `main` 分支根目录发布。此仓库仅包含公开展示内容及使用说明。
