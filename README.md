# 上海玄甲安全公司AI应用推进方案

以部门需求为主的交互式展示网页。电商部主用 Accio Work，其他部门主用 WorkBuddy，电商通用工作按需使用 WorkBuddy 辅助。

## 内容

- 开头的完整采购教学案例和术语解释
- 八个部门统一的六问任务说明与成果字段示意，包含财务报表分析
- 每页可直接讲述的讲稿和常见追问
- 可填写并下载的首批任务卡
- 组织分工、培训、公共资料与 Skill 维护
- 验收、阶段推进、每周复盘及台账
- 末尾飞书备用介绍与对比

## 使用

浏览器直接打开 `index.html`。左右方向键翻页，N 显示逐页讲稿，F 全屏。也可切换连续阅读或打印。

页面无外部脚本、字体和图片依赖，无统计跟踪或服务器端数据收集。任务卡填写内容仅在当前页面中使用，不上传；可下载为TXT，刷新后重置。

## 部署

使用 GitHub Pages，从 `main` 分支根目录发布。此仓库仅包含公开展示内容及使用说明。
